# Buscaminas

Ejercicio de JavaScript realizado durante el primer curso del ciclo de Desarrollo de Aplicaciones Web (DAW), cuando estaba aprendiendo a trabajar con arrays, eventos y manipulación del DOM.

Es una versión sencilla del Buscaminas clásico: genera un tablero con minas aleatorias, permite colocar banderas y descubre automáticamente las casillas vacías contiguas.

## Cómo ejecutarlo

Abre `buscaminas.html` en un navegador. Al iniciar, se solicitan el tamaño del tablero y el número de minas.

No necesita dependencias ni servidor.

## Conceptos practicados

JavaScript, matrices bidimensionales, recorrido de casillas adyacentes, eventos del ratón y actualización del DOM.

Se ha revisado posteriormente para corregir errores de coordenadas, controlar la entrada del usuario y evitar variables globales accidentales. Sigue siendo un ejercicio de aprendizaje, no un juego comercial.
